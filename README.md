## 独立站一定要自己买服务器吗，VPS、云服务器、独立服务器怎么挑

不一定。用 Shopify、Shopline 这类 SaaS 建站，服务器由建站公司负责，你只管内容和投放。选开源方案自己搭（WordPress、WooCommerce、OpenCart、Magento），才需要自己买或租服务器。SixtyNet 这类 KVM VPS 提供标准系统环境，上面这几种程序都能装。

三种形态的差别很直接：

- **独立服务器**：一台物理机归你用，性能最好，价格也最高。中小独立站基本用不上，日订单上千、或者库里几万个 SKU 要跑复杂查询才值得考虑。
- **虚拟专用服务器（VPS）**：一台物理机切出来的独立份额，价格低，个人卖家负担得起。风险在于物理机和虚拟化层任何一层出问题，网站都会打不开。
- **云服务器**：有独立操作系统，稳定性和安全性比 VPS 好一档，价格居中，配置能随时升降。

判断规则可以压成一句：SaaS 起步不用买；预算紧、流量可控选 VPS；订单稳定、怕宕机选云服务器；高并发、大数据库才上独立服务器。服务器直接决定网站能不能打开，这一项不适合压到极限。

## 机房放哪：SixtyNet 只有洛杉矶，什么情况下够用

SixtyNet 目前的产品线全在美国洛杉矶。选址的第一原则是服务器离目标客户最近，洛杉矶覆盖北美西岸最直接，美国东西岸之间、以及加拿大和墨西哥的访问都在可接受范围。

买家在英国、德国、法国，洛杉矶也能用，欧洲访客的延迟会比美西访客高，但靠 CDN 能补掉大部分静态资源的加载时间。买家集中在东南亚、日本、韩国，洛杉矶的物理距离摆在那里，延迟会明显高于新加坡、东京或香港的机房，这种场景 SixtyNet 给不了解法。

国内团队登录后台的体验是另一件事，取决于回程线路。第三方测评文对 SixtyNet 住宅机做过路由测试，电信去程走 CN2 直连洛杉矶，联通和移动直连洛杉矶；回程电信和移动走 CN2，联通走 AS10099 加 AS9929。高防系列的说法是去程 163 高防直连、电信 CN2 GIA 回程。

## 配置和带宽怎么定，别为用不上的资源付钱

内存：轻量 WordPress 配 Nginx 加缓存插件，1G 到 2G 就够跑。装了一堆插件、同机放多个站、或者用 WooCommerce 带几百个商品，上 4G 更保险，内存溢出的后果是站点直接挂掉。

带宽：电商站建议 5Mbps 以上，这是固定带宽口径下的经验值。SixtyNet 卖的是峰值带宽加流量包，LAX-STARTER 给 2Gbps 峰值、5TB 流量，两种计费模型不能直接比数字。5TB 对日均几百到一两千 PV 的展示型或小型电商站够用；跑视频、大量高清产品图，优先看 LAX-Storage 系列的硬盘配额，500G 那档给的是 300G 加 200G 赠送的 RAID 10。

架构：日订单 100 以内，一台机器加 CDN 就够，LAX-STARTER 或 LAX-MICRO 对应这个阶段。100 到 1000 单，需要多台机器加负载均衡，单台 VPS 开始成为瓶颈。超过 1000 单，考虑多地域集群、数据库读写分离和缓存层，这时候该评估的是云厂商而不是单台 VPS。

## FAQ

**独立站必须买服务器吗？**
看你选哪种建站方式。SaaS 建站由建站公司负责服务器，你不用管。开源建站必须自己买或租，没有服务器网站就没法显示给客户。

**2G 内存够跑 WooCommerce 吗？**
商品几百个、插件控制在十个以内的轻量站够用。商品上千、装了多语言和多币种插件、或者同机放多个站，直接上 4G，LAX-MICRO 比 LAX-STARTER 贵 200 美元/年，比站点因为内存溢出挂掉划算。

**买家在欧美，机房选洛杉矶还是香港？**
欧美买家选洛杉矶。香港机房的价值在国内外双向访问和低延迟，国内访问能到 10 到 30ms，但价格明显更高、库存也常告罄。SixtyNet 目前只有洛杉矶，这个选择在它这里不存在。

**流量超了会停机吗？**
SixtyNet 官网公开页面没有写超额后的处理方式，这一点必须开工单确认。同类商家里有做限速不断线的（比如 DMIT 是限速到 100Mbps 到 1Gbps），也有直接停机的，别默认。

**IP 被封了怎么办？**
官网公开页面没有列出 IP 更换政策，需要工单申请。住宅 IP 系列的卖点之一就是 IP 纯净度高、被封概率低，但 80 和 443 关着，本来也不适合放站。建站用的 LAX 系列是常规机房 IP，做正规外贸站被封的概率不高。

**退款要多久，有什么条件？**
发票开具后 3 天内申请，已用流量不超过 5GB，扣除手续费后原路退回。IRVINE-PRO 系列只退网站余额。
